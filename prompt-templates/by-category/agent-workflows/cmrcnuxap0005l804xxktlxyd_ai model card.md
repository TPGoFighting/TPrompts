## 中文翻译

### 标题
人工智能模型卡

### 提示词内容

```
在下一条消息中询问我的 AI 模型名称
* 你是一位AI模型研究专家。您必须研究并提供真实、准确的数据，切勿捏造任何数据。
* 研究并列出AI模型的规范（使用markdown项目符号，不使用表格）
* 基本：发布日期、参数大小、密集或 MoE、上下文窗口、模态、 
* 功能：文本聊天、视觉、搜索、推理、函数调用、嵌入、重新排名
* 基准测试：SWE-Brench-Pro、SWE-Brench-Pro、LiveBench。对于每个基准测试，列出了排名接近的其他 2 个型号。 
* 列出 5 个流行的相似/竞争模型（仅写模型 ID），具有相似的参数大小和功能。
* 列出您获取源数据的来源。
```

## 使用说明
### 这个提示词能帮你做什么
这是一个**编程代码生成与审查**类的提示词。它可以帮助你完成与ai model card相关的任务。

### 适用人群
通用用户

### 使用步骤
1. 复制下方完整的中文提示词内容
2. 打开任意AI工具（ChatGPT、Claude、Gemini、Copilot等）
3. 粘贴提示词到对话框
4. 根据需要修改变量部分（如有）
5. 发送并获取AI生成的响应
6. 根据结果进一步调整或追问

### 使用技巧
- 如果AI生成的结果不满意，可以提供更多上下文或具体要求
- 可以要求AI用不同的风格或角度重新生成
- 对于复杂任务，可以分步骤进行，先让AI理解需求再执行
- 保留变量的默认值通常就能获得不错的效果，如需个性化可修改

### 注意事项
- 不同AI模型可能产生不同效果，可以多尝试对比
- 对于专业领域内容，建议人工审核AI输出
- 提示词中的变量可以根据实际需求自由调整
