## Prompt Content

```
Write a ${tone:professional|friendly} email to ${recipient} about ${topic}.

The email should:
- Be approximately ${length:200} words
- Include a clear call to action
- Use ${language:English} language
```

### 标题

### 提示词内容

```
向 ${recipient} 写一封关于 ${topic} 的 ${tone:professional|friendly} 电子邮件。

电子邮件应：
- 大约 ${length:200} 个字
- 包括明确的号召性用语
- 使用${language:English}语言
```

## 使用说明

这是一个**创意写作与故事创作**类的提示词。它可以帮助你完成与Write an Email相关的任务。

### 适用人群
通用用户

### 使用步骤
1. 复制下方完整的中文提示词内容
2. 打开任意AI工具（ChatGPT、Claude、Gemini、Copilot等）
3. 粘贴提示词到对话框

5. 发送并获取AI生成的响应
6. 根据结果进一步调整或追问

- `${tone}`: 可自定义（默认值: professional|friendly）
- `${recipient}`: 需要您填写

- `${language}`: 可自定义（默认值: English）
