# TPrompts IP 世界观设定｜「提仔 Tippy」

## 01. IP 名称

**中文名：提仔**  
**英文名：Tippy**  
**身份：来自 Prompt 星球的「灵感采集员」**

提仔是一只生活在 **Prompt Planet（提示词星球）** 上的荧光绿色小生物。

在 Prompt Planet 上，人类每一个没有说完的想法、突然冒出的灵感、写到一半的需求，都会变成漂浮在宇宙里的「Idea Particle —— 灵感粒子」。

提仔的工作，就是把这些散落的灵感收集起来，把模糊的想法整理成真正可以被 AI 理解的 **Prompt**。

它相信一件事：

**Good ideas deserve good prompts.**

---

## 02. 提仔为什么是绿色的？

Prompt Planet 上存在一种特殊能量：

**Prompt Energy / 提示能量**

每当一个模糊的想法被整理成清晰、好用的提示词时，就会产生一颗绿色的 Prompt Energy。

提仔长期吸收这种能量，因此整个身体变成了非常显眼的 **TP Lime Green**。

所以它身体越亮，意味着：

> 最近又发现了很多好 Prompt。

这也让绿色不仅是 TPrompts 的品牌色，而成为整个 IP 世界观中的「灵感能量颜色」。

---

## 03. 头顶的触角

提仔头顶的触角叫：

### Prompt Radar

它可以接收到世界各地微弱的「灵感信号」。

比如：

“帮我做一个网站……”

“我想画一张图，但是不知道怎么描述……”

“有没有更好的 Claude Prompt？”

“这个需求应该怎么告诉 Codex？”

这些人类没有整理好的想法，都会被 Prompt Radar 捕捉到。

当附近出现一个很有潜力的想法时，触角顶端的小球就会：

**亮起来。**

---

## 04. TP 方块

提仔经常抱着一个黑绿色的小方块：

### TP Core

它是 TPrompts 世界里最重要的装置。

里面储存着大量 Prompt：

**Writing / Code / Image / Study / Marketing / Creative / Agent……**

当提仔找到一个模糊需求时，就会把它放进 TP Core。

经过整理、组合、测试以后：

**Idea → Prompt → Better Result**

最终生成一个更清楚、更有效、更容易被 AI 理解的 Prompt。

所以 TP Core 也可以成为 TPrompts 非常重要的品牌视觉符号。

---

## 05. 提仔的性格

提仔不是一个“无所不知的 AI”。

它更像一个：

**非常喜欢研究 AI 的朋友。**

它好奇、活泼、有一点呆萌。

看到新的 AI 工具时：

**“这是什么？让我试试！”**

发现一个好 Prompt 时：

**“这个得收藏起来！”**

Prompt 不够好的时候：

**“等等，我觉得还能再改一下。”**

生成成功的时候：

**“Good Prompt!”**

偶尔 Prompt 写错了，它也会露出尴尬的表情，然后默默重新修改。

所以它并不是完美的“专家形象”，而是一个不断：

**发现 → 尝试 → 优化 → 分享**

的 AI 探索者。

---

## 06. 提仔每天在做什么？

### ① Discover

戴上耳机和放大镜，在 Prompt 世界里寻找新的灵感。

**Discover Better Prompts.**

---

### ② Search

钻进 TPrompts 的 Prompt Library。

在大量提示词里寻找：

> “有没有人已经写过类似的 Prompt？”

---

### ③ Craft

打开电脑，把模糊的需求一点一点整理。

**Crafting better prompts…**

---

### ④ Test

拿出自己的 Prompt Checklist：

- 目标清楚了吗？
- 上下文够不够？
- 输出格式说明了吗？
- 有没有更好的写法？

全部打勾以后：

**Ready to generate ✓**

---

### ⑤ Generate

抱着 TP Core 等待 AI 生成结果。

这时候提仔通常会非常认真地盯着屏幕：

**Preparing your prompt…**

---

### ⑥ Learn

如果 Prompt 效果不好，它不会放弃。

而是戴上学士帽开始研究：

**“为什么这个 Prompt 不好用？”**

不断学习新的模型、新的方法、新的 Prompt Engineering 技巧。

---

### ⑦ Share

当它找到一个真正好用的 Prompt，就会坐上纸飞机，把它送到 Prompt Planet 的其他地方。

因此纸飞机代表：

**分享 / 发布 / 社区传播。**

---

## 07. 提仔的最大目标

Prompt Planet 上散落着无数未经整理的灵感。

很多好想法最终没有实现，并不是因为想法不好，而是：

**没有被正确地表达给 AI。**

因此提仔决定建立一个地方：

# TPrompts

把世界各地优秀的 Prompt 收集起来。

让每个人在面对 AI 时，都不需要从一个空白输入框开始。

这里可以：

**Discover.  
Copy.  
Create.  
Share.**

最终让：

> 每一个好想法，都能找到属于它的好 Prompt。

---

**Discover Better Prompts.**

**Craft Better Prompts.**

**From idea to prompt.**

**Prompt it better.**

以及最适合提仔自己的口号：

# Good Prompt!

## 09. IP 内容可以继续发展的故事线

以后网站、Loading、404、空状态、社交媒体都可以变成提仔的“小剧情”。

例如：

搜索页面：

**提仔拿着放大镜寻找 Prompt。**

Loading：

**提仔抱着 TP Core：Preparing your prompt…**

收藏成功：

**提仔把 Prompt 放进自己的收藏盒。**

404：

**提仔拿着地图：Where did this prompt go?**

没有搜索结果：

**提仔翻空箱子：No prompts found… yet.**

创建 Prompt：

**提仔坐在电脑前：Crafting better prompts…**

发布成功：

**提仔坐纸飞机把 Prompt 发出去。**

热门 Prompt：

**提仔举着牌子：Good Prompts!**

学习页面：

**提仔戴学士帽看 Prompt Engineering 手册。**

这样它就不只是一个 Logo 吉祥物，而会逐渐成为贯穿整个 TPrompts 产品体验的角色。

## 10. 一句话世界观

**提仔是一只来自 Prompt Planet 的灵感采集员，它每天在互联网和 AI 世界里寻找散落的好想法，把它们整理成更好的 Prompt，再分享给所有人。**
